# Seungheon Doh — CV Site

A dependency-free academic CV site built with HTML, CSS, and JavaScript.

## Local preview

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## CV download

Add the current PDF CV as `assets/cv.pdf`. The CV link is enabled automatically when the file is available.

## Deployment

Configure GitHub Pages to publish from the default branch and repository root. No build command is required.
